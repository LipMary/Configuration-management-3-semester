# Практическая работа №1 — Эмулятор командной строки Linux

Эмулятор терминала UNIX-подобной операционной системы, написанный на языке Python 3. 

## Выполненные этапы
В соответствии с требованиями были реализованы **первые 3 этапа** практической работы:
1. **Этап 1:** Разработка каркаса эмулятора на базе цикла REPL.
2. **Этап 2:** Настройка конфигурации (запуск с аргументами командной строки и выполнение стартового скрипта).
3. **Этап 3:** Создание виртуальной файловой системы (VFS) на основе базы данных в формате CSV.

## Структура проекта
* `emulator.py` — основной код программы-эмулятора.
* `vfs.csv` — таблица со структурой виртуальных папок и файлов.
* `script.txt` — стартовый скрипт с командами для автоматического выполнения при запуске.
